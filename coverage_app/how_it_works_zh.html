Coverage 应用的运行链路

两条链路：在 Generate 页点击 Generate coverage database 后发生了什么；以及 Database 和 Dashboard 页上的数据和统计数字从哪里来。每一步都标出了文件、行号和函数，点击位置即可在编辑器中打开。

浏览器：coverage_app/static/ 本地服务器：coverage_app/server.py Python 脚本：code/check_coverage_database.py 磁盘上的文件

总览

A. 生成 coverage database

按钮在 Generate 页。浏览器本身不运行 Python：它把路径发给本地服务器，由服务器在后台线程里运行脚本。

  1. 1

    按钮

    浏览器
    <button id="btn-generate">

    普通的 HTML。页面上它旁边是 Final CSV 输入框（in-csv）、Staff reports folder（in-pdf）、 子文件夹选择和 Version stamp。

  2. 2

    点击处理：发出请求

    浏览器
    $("btn-generate").addEventListener("click", …)

    先重新检查路径（inspectPaths() → POST /api/inspect），收集勾选的子文件夹，然后通过 api()（第 22 行，一个简单的 fetch 封装）把 {final_csv, pdf_root, batches, stamp} 发到 /api/generate，接着开始轮询进度。请求的接收方是本机上运行的 server.py，不是云端 API。

  3. 3

    服务器收到 POST

    本地服务器
    Handler.do_POST()

    把 /api/generate 交给 start_job()。

  4. 4

    检查输入，启动后台线程

    本地服务器
    start_job(body)

    检查 CSV 和文件夹是否存在、stamp 是否合法、是否已有任务在运行。用 unique_stamp()（第 93 行）保证版本号不重复 （已存在就加 _2、_3 …），然后在线程里启动 _run_job 并立即回复，页面不会卡住。

  5. 5

    真正运行 Python 代码的那一行

    本地服务器
    _run_job() → ccd.main(final_csv=…, pdf_root=…, out_dir=…, stamp=…, batches=…, progress=_progress)

    ccd 就是 check_coverage_database，在 server.py:46 导入。脚本打印的内容被收进任务日志 （_LogWriter），_progress()（第 172 行）更新进度条。它和命令行运行 python code/check_coverage_database.py 用的是同一个 main()。

  6. 6

    main()：构建并保存一个版本

    Python 脚本
    main()

    依次调用 build()、by_year()，然后写出工作簿和运行记录（JSON，记录 CSV 的大小、修改时间和 SHA-256）。

  7. 7

    build()：每个国家每一年一行

    Python 脚本
    build()
    • 数值：load_rows() 读取 final CSV，并给每行确定“数值所属的年份”；国家名称经 normalize_country() 统一。
    • Staff report：read_pdfs() 列出所选子文件夹里的 PDF，从文件名读出国家和发布年份； keep_panel_reports() 去掉区域性报告； report_country_years() 得到 (国家, 年份) 组合。
    • 数值来源：value_sources() 当多个轮次都有值时，按 Round 1 → Round 2 → Round 3 → Gap fill 的顺序取一个。
    • 指标列：indicator_columns() 为每个 hierarchy_id 命名一列（如 h6_residual）。
  8. 8

    保存到 output/coverage/

    文件
    write_workbook()

    coverage_database_<STAMP>.xlsx，包含 Coverage（Yes/No）、By year、Sources、 Report years、Indicators、Notes 几个 sheet；以及 coverage_database_<STAMP>.json（版本记录）。 保存位置由脚本设置里的 OUT_DIR 决定。

  9. 9

    进度条和版本历史

    浏览器
    pollJob() → GET /api/job

    每秒问一次服务器任务进行到哪一步（setJobState()，第 99 行，负责画进度条）。完成后 loadRuns() （第 164 行 → GET /api/runs → server.py 第 65 行的 list_runs()）刷新版本列表， 版本列表就是文件夹里所有的 coverage_database_*.xlsx + .json。

B. Database 与 Dashboard

数据从哪里读、分析在哪里做。
① 查看时不会重新运行 check_coverage_database.py。server.py 里的一个函数从本地 output/coverage/ 读取已保存的 xlsx（不是 final CSV），转成紧凑的 JSON 发给页面。Database 和 Dashboard 共用这一份数据，每个版本只读一次。
② Python 脚本负责算出每个国家每一年的事实（有没有值、来自哪一轮、哪些年份有 staff report），保存在工作簿里，即 build()。
③ 页面上的统计数字（按年份和来源的计数、Unavailable、T+1…T+4 的拆分、顶部三个数字）是在浏览器里、在 app.js 中计算的：yearBreakdown() 和 drawChart()。所以切换指标或 T+k 是即时的，不需要再跑 Python。
工作簿里的 “By year” sheet（by_year()，脚本第 303 行）是给 Excel 用的另一份汇总，Dashboard 不读取它。
  1. 1

    选择一个版本

    浏览器
    setActive(stamp)

    在打开页面时或切换 Version 下拉框时运行（不是在点击 Database 标签时）。请求 GET /api/runs/<stamp>/data， 返回的数据存在 S.data 里，Database 和 Dashboard 两个页面都用它。

  2. 2

    分发请求

    本地服务器
    Handler.do_GET()

    用 workbook_for()（第 87 行）找到这个版本对应的工作簿，然后调用 coverage_payload()。

  3. 3

    读取已保存的工作簿，压缩后发出

    本地服务器
    coverage_payload(path)

    用 pandas 的 read_excel（第 115 行）读取各个 sheet，对 4,750 行生成：每行的国家和年份；每列一串 1/0（来自 Coverage）；每个指标一串来源代码 1 2 3 g 0（来自 Sources）；每个国家的 发布年份（来自 Report years）。这里不做任何统计，只是换个格式。最近读过的工作簿会缓存在内存里，文件改动后会自动重新读取。

  4. 4

    Database 表格

    浏览器
    renderDatabase()
    filteredRows()

    点击 Database 标签只是把这一部分显示出来（showTab()，第 35 行）。国家、年份筛选、翻页和 Fields 选择都在浏览器里完成， 不会再向服务器请求。Download workbook 按钮则把同一个 xlsx 原样发给你。

  5. 5

    指标选择和 T+k 切换

    浏览器
    setupSlicer()
    setSpan(k)

    每次改变都会重新调用 drawChart()。按钮本身在 index.html:147。

  6. 6

    统计数字

    浏览器
    yearBreakdown(ind, k)
    reportLookup()
    • 把所有国家-年份行遍历一次。每一年统计：total，以及根据所选指标的来源代码分到 r1 r2 r3 gf；代码 0 计入 unavail。
    • 打开 T+k 时：对第 T 年 unavailable 的国家，查它在 T+1 … T+k 年是否有 staff report（来自 reportLookup()）。 一份都没有 → nolater（带阴影的部分，国家名加入 list）；否则 → later（Unavailable, other reasons）。
    • partial 标记 T+k 超出 PDF 最后年份的年份（图上的 *）。
  7. 7

    画图

    浏览器
    drawChart()

    顶部三个数字（country-years、有数据的数量、覆盖率）、堆叠柱状图（SVG）、柱子上方的数字、悬停提示、点击柱子后的国家列表， 以及 “Show the numbers” 表格，全部来自 yearBreakdown() 的结果。
