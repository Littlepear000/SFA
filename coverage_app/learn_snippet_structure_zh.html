Snippet 的代码结构，一步步讲清楚

配合 coverage_app/learn_year_breakdown_zh.html 使用。这页回答：代码哪里有问题、第一行为什么标红、整体应该怎么摆放， 并按 Python 的说法逐段解释这段 JavaScript。

问题 1代码哪里有问题？第一行为什么标红？

代码本身没有问题，我在测试数据上原样运行过，结果正确。 第一行的红色是上一次运行留下的报错标记，不是这一行写错了。

上一次的报错是 Uncaught EvalError … at eval (Script snippet #1:1:1)。最后的 :1:1 表示“第 1 行第 1 个字符”。 DevTools 会把报错发生的位置标红，并在旁边放一个红色图标，鼠标悬停能看到报错内容。

当时报错是因为页面还停在 app.js 第 400 行的断点上。那时运行 Snippet，它会被塞进 yearBreakdown 函数里面执行， 那里不允许新定义函数，所以一开头就失败了。

怎么让红色消失

  1. 继续运行页面顶部如果有黄色的 “Paused in debugger”，按 F8，直到黄条消失。
  2. 取消第 400 行断点打开 app.js，点一下蓝色的行号 400，蓝色消失即取消。
  3. 重新运行 Snippet回到 Snippet，按 Cmd+Enter。这次运行成功，红色标记就会被清掉 （修改一下代码也会清掉）。

问题 2整体结构应该是什么样的？

一共涉及 DevTools 里的三个地方，各管各的事：

地方是什么你要做的
Sources → app.js页面自己的代码，S.data 在这里只用来取一次数据，不修改。取完记得取消断点
Console一个输入框，输一句、执行一句，类似 Python 交互式命令行输入一次 window.D = S.data（或 fetch 那段）。之后在这里看打印结果
Sources → Snippets可以保存的脚本文件，类似一个 .py 文件粘贴学习脚本，Cmd+Enter 运行

完整顺序

  1. 打开 app，选好版本双击 start.command，Version 下拉框选一个带 Sources 和 Report years 的新版本。
  2. 取数据（现在可以跳过）Snippet 最后一段会自己取 D，这一步不做也行。想在 Console 里单独看数据时再做：
    · 没有断点时，在 Console 粘贴 fetch 那段（见学习页第一步）；
    · 或者在 app.js 第 400 行打断点 → 切到 Dashboard 停住 → Console 输入 window.D = S.data → F8 继续 → 取消第 400 行断点。
  3. 检查 DConsole 输入 D 回车，能看到一个可展开的对象，里面有 sources 和 report_years。
  4. 运行 Snippet确认页面没有暂停黄条，打开 Snippet，Cmd+Enter。
  5. 逐行走停在 debugger 后按 F10 一行一行走，看右侧 Scope 面板；走完这一行按 F8。
  6. 看结果Console 里出现检查过程和最后的表格。

问题 3Snippet 里的代码是怎么组织的？

整个 Snippet 分三块。和 Python 脚本一样：上面先定义函数，最下面几行才真正运行。

所以按 Cmd+Enter 后，浏览器先“读”完 A 和 B（只记住它们，不执行），然后执行 C。C 先取数据 D，再调用 B，B 再调用 A。

A · reportLookup建一张“哪个国家哪年有报告”的查询表

  

  

    
B · yearBreakdownLearn主体：逐行计数（和 app.js 的 yearBreakdown 逻辑一样）

    

  

  

    
C · 运行取数据 D → 选指标 → 调用 B → 打印表格

A reportLookup(d)

  

    
JavaScript意思Python 大致等于

    
      
function reportLookup(d) { … }
定义一个函数，参数叫 d。花括号 { } 里是函数体（Python 用缩进）
def report_lookup(d):

      
var sets = d.countries.map(
  function () { return {}; });
每个国家对应一个空字典，组成列表。map 对列表每个元素调用一次函数，收集返回值
sets = [{} for _ in d["countries"]]

      
d.report_years.forEach(function (ys, c) {
  ys.forEach(function (y) {
    sets[c][y] = 1; }); });
两层循环：对第 c 个国家的每个报告年份 y，记 sets[c][y] = 1
for c, ys in enumerate(d["report_years"]):
    for y in ys:
        sets[c][y] = 1

      
return { sets: sets,
  last: d.report_year_range[1] };
返回一个对象，两个字段：查询表和最后一个报告年份
return {"sets": sets,
  "last": d["report_year_range"][1]}

B yearBreakdownLearn(d, ind, k, watchCountry, watchYear)

  
五个参数：数据 d、指标名 ind、T+k 的 k、要盯住的国家和年份。

  

    
JavaScript意思Python 大致等于

一行声明两个变量：空字典 by（按年份放计数），和 A 建好的查询表 rep
by = {}
rep = report_lookup(d)

      
var src = d.sources[ind];
这个指标每一行的来源代码，是一长串字符，如 "0g1100…"
src = d["sources"][ind]

      
var series = [{ key: "r1", code: "1" }, …];
来源代码和计数名的对照表
series = [{"key": "r1", "code": "1"}, …]

      
for (var i = 0; i < d.row_year.length; i++) {
从 0 数到行数减 1。i++ 就是 i += 1
for i in range(len(d["row_year"])):

第 i 行的年份和国家编号
y = d["row_year"][i]
c = d["row_country"][i]

是不是要盯的那一行。=== 是“等于”，&& 是“并且”
watch = (d["countries"][c] == watch_country

是的话就在这里暂停
if watch: breakpoint()

      
var b = by[y];
if (!b) {

}
取这一年的计数桶；没有就新建，各项从 0 开始。!b 是“b 不存在”

b.total++;

总数加 1，取这一行的来源代码
b["total"] += 1
code = src[i]

}
有值：找到对应的来源，给它加 1，跳到下一行。!== 是“不等于”

b.unavail++;

走到这里说明没有值。k 为 0（Off）时不再细分
b["unavail"] += 1
if not k: continue

}
核心判断：查 y+1 到 y+k 每一年有没有报告，有一年有就停
none = True
for j in range(1, k + 1):

        none = False; break

      
if (none) { b.nolater++;
  b.list.push(d.countries[c]); }
else b.later++;
都没有 → 斜线部分加 1，国家名加入名单；否则实心灰加 1。push 就是 append

return Object.keys(by).sort()
  .map(function (y) { return by[y]; });
年份排好序，按顺序取出每年的计数，返回一个列表
return [by[y] for y in sorted(by)]

问题 6定义完函数后，怎么从头逐行跑？

  
先定义函数是对的。定义只是登记，函数里的代码在被调用之前一行都不会执行。
    所以断点要打在调用的地方，停下后按 F11 走进函数，里面就能一行一行走了。

  
    
    
  1. 先确认能暂停新建一个 Snippet，只写一行 debugger; console.log("hello");，Cmd+Enter。
      不停的话，说明断点被整体停用了：看 Sources 右上角那个“斜杠箭头”图标（Deactivate breakpoints）是不是蓝色的，点一下或按 Cmd+F8 恢复。
    2. 
    
  2. 在调用处打断点回到学习 Snippet，点 C 段 var rows = yearBreakdownLearn(…) 那一行的行号，变蓝。
    3. 
    
  3. 运行光标先点进 Snippet 编辑区，再 Cmd+Enter。停在这一行（函数还没开始执行）。
    4. 
    
  4. F11 走进去高亮跳到 B 的第一行 var by = {}, …。之后：
      
    · F10：执行当前行，到下一行（遇到函数调用不进去）
      
    · F11：遇到函数调用就走进去，比如在 rep = reportLookup(d) 这一行按，会进入 A
      
    · Shift+F11：从当前函数里走出来，回到调用它的地方
      
    · F8：一直跑，直到下一个断点或结束
    5. 
    
  5. 想直接跳到阿尔及利亚 2005在循环里逐行走要走很多遍。按 F8，会停在 if (watch) debugger;（那一行才满足条件），再接着按 F10。
    6. 
  

  
如果按 Cmd+Enter 后什么都没停，但 Console 打印出了表格，说明代码跑完了却没暂停，看第 1 步。

附常见报错对照

  

    
报错原因怎么办

    
      
S is not defined没停在断点上，Console 看不到私有变量 S用 fetch 取数据，或先停在断点

      
missing ) after argument list停在断点时用了 fetch 那段（里面的 await 在暂停时不能用）暂停时改用 window.D = S.data

      
Identifier '…' cannot be declared with 'var'运行 Snippet 时页面正处于暂停状态。看报错第二行 at …(app.js:行号) 就知道停在哪：yearBreakdown (app.js:400) 是第 400 行断点；setDefaultStamp (app.js:136) 是没暂停时多按了一次 F8（这时 F8 是“暂停”），停在了每 20 秒跑一次的代码上按一次 F8，确认黄条消失、右侧按钮显示 ⏸ 而不是 ▶；取消所有断点，再运行。没暂停时不要按 F8

      
D is not defined还没取数据，或者刷新过页面（D 被清掉了）重新做“取数据”那一步

      
Cannot read properties of undefined (reading 'forEach')选的是旧版本，没有 report_years / sources换一个新版本，或在 IMF 电脑上重新生成

      
运行了但没有暂停按过 Cmd+F8 停用了断点；或国家名拼写不对；或 DevTools 没打开再按一次 Cmd+F8 恢复；国家名照 D.countries 里的写
